안녕하세요. 소프트웨어 개발자로서 사용자에게 가치 있는 서비스를 제공하고 싶은 김민수입니다.

저는 대학에서 컴퓨터공학을 전공하며 프로그래밍의 기초를 다졌고, 졸업 후 2년간 스타트업에서 웹 개발 업무를 담당했습니다. 빠르게 변화하는 IT 업계에서 새로운 기술을 학습하고 적용하는 것에 큰 흥미를 느끼며, 특히 사용자 경험을 개선하는 기술적 솔루션을 찾는 것을 좋아합니다.

현재 저는 혁신적인 기술력과 우수한 개발 문화를 갖춘 회사에서 저의 기술적 역량을 더욱 발전시키고 의미 있는 프로젝트에 기여하고 싶습니다.

생활신조

"기술은 사람을 위해 존재한다"

개발자로서 항상 사용자의 관점에서 생각하려 노력합니다. 아무리 기술적으로 뛰어난 코드라도 실제 사용자에게 도움이 되지 않는다면 의미가 없다고 생각합니다. 사용자가 더 편리하고 효율적으로 업무를 처리할 수 있도록 돕는 것이 개발자의 사명이라고 믿습니다.

주요 강점

📚

꾸준한 학습 의지

새로운 기술 트렌드에 관심이 많아 개인 시간을 활용해 온라인 강의를 수강하고 사이드 프로젝트를 진행합니다.

🤝

협업과 소통

팀 프로젝트에서 다른 개발자, 디자이너, 기획자와 원활히 소통하며 공동의 목표를 달성하는 것을 중요하게 생각합니다.

🔧

문제 해결 지향적

복잡한 버그나 기술적 이슈에 직면했을 때 포기하지 않고 다양한 접근 방법을 시도하여 해결책을 찾습니다.

개선하고 있는 점

완벽주의 성향

때로는 코드의 완성도에 지나치게 집착하여 일정에 영향을 줄 수 있습니다. 이를 개선하기 위해 우선순위를 명확히 하고 적정 수준의 완성도를 목표로 하는 연습을 하고 있습니다.

01. 학창시절 경험

교내 해커톤 우수상 수상

대학교 3학년
2019

"지역 상권 활성화 앱"을 개발하여 우수상을 수상했습니다. 팀장을 맡아 5명의 팀원과 함께 48시간 동안 React Native로 모바일 앱을 완성했습니다.

특히 백엔드 API 설계부터 프론트엔드 구현까지 전 과정에 참여하면서 풀스택 개발 경험을 쌓을 수 있었고, 짧은 시간 내에 팀원들의 역량을 파악하고 업무를 효율적으로 분배하는 리더십을 발휘했습니다.

  • React Native
  • Node.js
  • Express
  • MongoDB
  • 팀 리더십

학회 멘토링 활동

컴퓨터공학과 학회
2016 — 2020

대학교 4년간 컴퓨터공학과 학회에서 활동하며 후배들에게 프로그래밍을 가르치는 멘토링을 진행했습니다.

복잡한 개념을 쉽게 설명하는 능력을 기를 수 있었고, 이는 현재 팀 내에서 코드 리뷰와 기술 공유를 할 때 큰 도움이 되고 있습니다.

  • 멘토링
  • 지식 공유
  • 커뮤니케이션
  • 교육 기획

웹 개발자

스타트업
2020 — 2022

졸업 후 2년간 스타트업에서 웹 개발 업무를 담당하며 실무 경험을 쌓았습니다.

사용자 경험을 개선하는 기술적 솔루션을 지속적으로 탐구하며, 빠르게 변화하는 IT 업계에서 새로운 기술을 학습하고 적용하는 능력을 기르고 있습니다.

  • JavaScript
  • React
  • Node.js
  • HTML & CSS
  • Git

03. 입사 후 포부

단기 목표 (0-6개월)

빠른 적응과 팀워크

귀사의 개발 문화와 코딩 컨벤션에 빠르게 적응하여 팀의 일원으로서 역할을 다하겠습니다. 맡은 업무를 성실히 수행하면서 귀사의 비즈니스 도메인에 대한 이해도를 높이고, 기존 팀원들과의 협업을 통해 개발 실력을 향상시키겠습니다.

  • 개발 문화 및 코딩 컨벤션 숙지
  • 비즈니스 도메인 이해도 향상
  • 팀 협업 강화 및 커뮤니케이션 개선

중기 목표 (6개월-2년)

기술 리더로의 성장

기술 리더로 성장하여 주니어 개발자들을 멘토링하고, 새로운 기술 도입과 개발 프로세스 개선에 기여하고 싶습니다. 특히 클라우드 기술과 마이크로서비스 아키텍처에 대한 전문성을 쌓아 서비스의 확장성과 안정성 향상에 기여하겠습니다.

  • 주니어 개발자 멘토링
  • 클라우드 기술 및 마이크로서비스 전문성 개발
  • 개발 프로세스 개선 및 새로운 기술 도입
  • 코드 품질 향상 및 아키텍처 설계 참여

장기 목표 (2년+)

혁신적인 서비스 개발

궁극적으로는 귀사와 함께 성장하여 IT 업계에서 인정받는 개발자가 되고, 사용자에게 진정한 가치를 제공하는 혁신적인 서비스 개발에 핵심적인 역할을 담당하고 싶습니다.

  • 업계에서 인정받는 기술 전문가로 성장
  • 혁신적인 서비스 개발 리드
  • 사용자 가치 창출에 집중한 제품 개발
  • 기술 커뮤니티 기여 및 지식 공유
