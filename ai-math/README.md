# 선택의 수학 · AI 추천 탐구실

공통수학의 행렬, 가중평균, 연립일차부등식으로 추천 모형을 탐구하는 4차시 정적 웹 콘텐츠입니다. 기존 저장소의 급식 앱은 변경하지 않았습니다.

## 실행

이 디렉터리에서 `python3 -m http.server 8010`을 실행한 후 브라우저로 접속합니다. HTML·CSS·JS만 사용하며 설치·빌드·API 키가 필요하지 않습니다. JavaScript 구문 검사는 `node --check script.js`로 실행합니다.

GitHub Pages가 저장소 루트에서 배포되도록 설정되어 있다면 `/ai-math/` 경로로 접근할 수 있습니다. 이 작업에서는 원격 업로드나 Pages 설정을 변경하지 않았습니다.

## 활동

1. 투자와 비중: 가상 기업 9개에 정수 주식으로 투자하고 5일간 거래합니다. 가격은 거래 중 비공개, 장 마감 후 공개합니다. 현금을 포함한 마감 직전 비중으로 하루 가중 수익률을 계산합니다. 뉴스와 시황은 고정 가상 시나리오이며 실제 투자 데이터가 아닙니다.
2. 행렬과 선택: 0.01 단위 가중치 슬라이더, 종합점수와 그래프, 행렬 계수 입력, 연립부등식 확인 활동을 제공합니다. 경계에서는 공동 추천합니다.
3. 가중치 추정: 1반 학생 25명의 선택으로 가중치를 추정·수정합니다. 선택 설명 여부와 실제 가중치 오차를 구분합니다. 25명 완료 후 실제 값과 분포를 공개합니다.
4. 데이터와 추천: 1반 모델을 2반에 적용한 뒤 2반 25명을 추정하고 교차 비교합니다. 학습에 사용한 집단의 일치율과 다른 집단에서의 일치율을 구분합니다.

브라우저 localStorage에 진행 상황과 서술형 답안을 저장하며, JSON으로 내보낼 수 있습니다. 자동 서버 제출, 기기 간 동기화, 기록 파일 가져오기는 포함하지 않습니다. 학생 이름 등 개인정보는 요구하지 않습니다. 초기화 시 해당 앱의 기록만 교체합니다.

이 콘텐츠는 선택 데이터에 따른 추천 변화를 살펴보는 단순화된 모형입니다. 학생 선택은 숨겨진 고정 가중치와 점수표로 생성됩니다. 평균 추정 가중치 하나가 모든 사람의 선호를 대표하지 않으며, 일치율은 관찰된 25명의 비율입니다.

마감 분석의 단순평균은 마감 직전 보유한 종목만 포함하며 현금은 제외합니다. 내 자산 수익률은 현금을 포함한 실제 비중으로 계산합니다. 미보유 종목의 시황은 별도 접이식 표에서 확인합니다.
